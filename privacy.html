Privacy Policy — Twisting Nether

Effective: 10 November 2026 · Applies to: Twisting Nether (Google Sheets panel), TN Control Center (Google Sheets panel), TN Warmup Agent (web app)

Who we are

Twisting Nether is an internal tool built and operated by our outreach team for its own use. It is not sold, licensed or offered to third parties. Contact: betujica193@gmail.com.

What the apps access and why

  • Google Sheets — the team's own spreadsheets that hold outreach queues, replies and statistics. The apps read them and write status cells and reports.
  • Gmail (read-only) — Twisting Nether reads the signed-in user's own mailbox to detect replies to outreach and whether test messages landed in Spam.
  • Gmail (send / modify) — TN Warmup Agent, running under the mailbox owner's own account, sends short internal messages to other team mailboxes listed in the shared Warmup Hub spreadsheet, replies in those threads, and moves messages from team mailboxes out of the Spam folder. It never sends mail to anyone outside the Hub list.
  • Google Drive — TN Control Center stores backups of the team's own Apps Script projects before updating them.
  • Apps Script projects — TN Control Center updates the code of the team's own Twisting Nether scripts.
  • Email address of the signed-in user — shown in the panel and used to match the user with their row in the shared Hub.

Where data is stored

All data stays in the team's own Google Workspace / Google account: Google Sheets owned by team members and Script Properties of the Apps Script projects. The apps run no external servers or databases.

The only external service used is the DeepSeek API, which generates neutral warm-up message texts. It receives only first names derived from mailbox addresses and a topic request — never mailbox contents, contact lists or message bodies of real correspondence.

Sharing

We do not sell, rent or share Google user data with third parties. Data is visible only to members of our team who have access to the corresponding spreadsheets.

Google API Services User Data Policy

Twisting Nether's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to provide the features described above, is not used for advertising, and is not read by humans except as needed for support with the user's consent.

Retention and deletion

Data lives in spreadsheets controlled by the team and is retained as long as the team keeps those spreadsheets. Any user can revoke the apps' access at any time at myaccount.google.com/permissions; the Warmup Agent can be switched off from its own page, which removes its scheduled trigger. To request deletion of data concerning you, write to the contact address above.

Changes

If this policy changes, the updated version will be published at this address.
